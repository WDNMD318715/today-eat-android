# 验证报告

版本：1.0.0（versionCode 1）  
验证日期：2026-11-06  
技术：原生 Android Java + 系统 SQLite；minSdk 26，targetSdk 35。

## 自动化验证

测试由 JUnit 4 + Robolectric 4.14.1 执行。数据库测试使用原生 SQLite 模式，并真实关闭和重新打开数据库文件。

| 验证内容 | 覆盖方式 |
| --- | --- |
| 保存后重新打开仍存在 | 关闭 SQLiteOpenHelper 后新建实例，验证饭菜全部字段、设置、确认记录 |
| 午晚餐正确筛选 | 验证「仅午饭」「仅晚饭」「都可以」的候选集合 |
| 停用不参与抽选，恢复后参与 | 持久化状态后重开数据库并检查候选 |
| 空列表、单候选 | 核心规则及 Activity 点击测试，验证管理入口和单候选提示 |
| 换一个不立即重复 | 固定随机种子执行 3000 轮，检查候选归属和相邻不重复 |
| 抽选不等于吃过 | 点击抽选及换一个后数据库没有历史，明确确认后才有记录 |
| 晚饭避开午饭 | 同一天排除、次日不排除、开关关闭、明确放宽的规则及交互 |
| 批量添加、去重、名称必填 | 包括已停用名称、前后空白、批次内重复、失败回滚 |
| 修改、删除不改变旧记录 | 历史字段快照、改名后按 ID 排除午饭、删除重加按名称排除 |
| 每餐确认替换 | 同日期同餐次只有一条记录，替换后按新午饭筛选 |
| 过时抽选结果保护 | 抽中后停用，确认时拒绝写入 |
| 界面与状态恢复 | Activity 重建后恢复未确认结果；确认后清除按钮防止重复提交 |
| 金额输入 | 分为整数存储，空值、零、两位小数、超范围和非法格式 |
| 页面渲染 | 以 393 × 852 dp 渲染原生 Android 视图，人工查看首页、结果、管理、记录 |

自动化测试总数：**19 项，全部通过**。详细原始结果在本目录 `test-results/`，页面渲染在 `screenshots/`。渲染图片中的示例饭菜只存在于测试环境，安装包首次启动没有预置饭菜。

## 构建与检查

- Release APK 使用独立 RSA 密钥签名，不是网页或 PWA。
- Android Lint 静态检查通过；Android 8.0 与 8.1+ 的导航栏样式已分开处理。
- APK 签名、包名、最低系统版本、权限和 ZIP 对齐校验结果见 `apk-verification.txt`。
- 应用 Manifest 未申请 INTERNET 或其他权限，关闭自动云备份和设备迁移备份。
- 源码、Gradle Wrapper、测试和构建脚本一并交付；签名私钥及下载的构建缓存不在源码 ZIP 中。

## 已知验证边界

当前没有连接 Android 实体手机或运行中的模拟器，因此未实际执行真机安装、整机重启、各手机品牌系统兼容性验证。数据库重开和 Activity 重建测试已通过，但不将其称为已完成真机重启测试。

请按「安装与使用说明」中的短清单在手机上做首次验收。卸载应用、清除应用数据会删除本机内容；本版没有云同步或导出备份。
